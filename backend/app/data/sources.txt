# @source | key | name | domain | country | type | scope
#   type : news | public_broadcaster | state_funded_broadcaster | official | company | specialist | factcheck | community
#          community = a link site where people or editors pick stories from many outlets (Hacker News, Techmeme). Its feed is
#          read with kind "community": each story is stored as the linked outlet's article when that outlet is collected.
#   scope: national = an article with no place of its own is about the outlet's country;
#          international = no such fallback (world coverage).
# feed  | source key | feed url | topic hints (comma separated codes) | place hints | kind (rss when empty; community, sitemap)
#   place hints: empty = follow the source's scope, "-" = never fall back to the outlet's country,
#                otherwise comma separated place codes (IN-TN, IN-TN-chennai, asia-pacific, ...)
#   A feed whose topic hint is a sub-topic (more than one level deep) is a specialist feed: it is polled
#   only while one of its hint topics is enabled in Settings -> Topics.
